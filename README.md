Приложение вида HelpDesk. Какие функции у приложения:
- Создать сотрудника
- Показать список сотрудников
- Создать задачу
- Удалить задачу
- Показать список задач
- Поставить флажок "выполнено" для задачи
- Для создания задачи необходима ее привязка к существующему сотруднику, следовательно нужно сначала создать сотрудника. Так же при создании задачи необходимо указать верный приоритет (от 1 до 5)
- Если вы при создании задачи получаете ошибку 400, то значит вы указали неверный приоритет, если 404, то значит указан неверный id сотрудника.
- Если при поиске задачи вы получаете ответ 404, то значит что вы ввели неверный id задачи. При выполнении задачи вы можете поставить флажок done, а так же удалить задачу.
- Сборка образа: docker build -t task_api .З
## Запуск через Docker
```bash
docker build -t task_api .
docker run --rm -p 5000:5000 -v $(pwd)/instance:/app/instance task_api
```
Работа на машине ведется через порт 5000, работа контейнера ведется через порт 5000. База данных находится в task_api/instance, внутри SQLAlchemy /app/instance
