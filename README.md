Приложение вида HelpDesk. Какие функции у приложения:
Создать сотрудника
Показать список сотрудников
Создать задачу
Удалить задачу
Показать список задач
Поставить флажок "выполнено" для задачи
Для создания задачи необходима ее привязка к существующему сотрдунику, следовательно нужно сначала создать сотрудника. Так же при создании задачи необходимо указать верный приоритет (от 1 до 5)
Если вы при создании задачи получаете ошибку 400, то значит вы указали неверный приоритет, если 404, то значит указан неверный id сотрудника.
Если при поиске задачи вы получаете ответ 404, то значит что вы ввели неверный id задачи.
При выполнении задачи вы можете поставить флажок done, а так же удалить задачу.
